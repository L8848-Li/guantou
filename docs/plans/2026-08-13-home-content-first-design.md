# 首页内容化改版设计草案（罐头沉浸流 + 自定义 TabBar）

## 状态

设计草案，待拆分为子任务实施。

## 背景与目标

当前首页是「门户导航页」：首屏由品牌区、搜索框和六宫格功能卡组成，真正的核心内容（罐头流）被压在最底部，加载失败时首屏只剩错误横幅。用户打开应用后必须先自行选择入口，决策成本高、情绪唤起低。

本草案将首页重构为「内容即首页」的沉浸式罐头流，目标是：

- 打开即看到罐头（一段录音 + 相关铭牌），零决策成本进入内容消费；
- 以铭牌投票作为最低门槛互动（类比点赞），形成「听 → 投票 → 关注 → 装罐」的粘性循环；
- 次要功能收进底部导航与顶部轻入口，让首屏聚焦核心。

参照对象：抖音（沉浸式单列流、右侧互动栏、中央凸起发布键）、Twitter/X（内容流 + 底部导航分工）。

## 范围声明

本文档只负责**排版布局与功能定义**，作为后续拆分子任务（子 issue）的依据，不包含具体代码实现细节。接口字段、组件拆分、路由改造等技术方案在各子任务中细化。

## 首页整体布局

```text
┌────────────────────────────────────┐
│ ○方言圈  今日罐 同方言 关注 推荐  ⌕ │ ← 顶部：轻入口 + 内容 tab + 搜索图标
├────────────────────────────────────┤
│   深色沉浸背景（深绿系渐变）          │
│                            [作者头像]│
│    ～～ 播放波形动画 ～～      [♥]   │ ← 右侧竖排轻互动栏
│    ▶ 播放 · N 秒              [💬]   │
│    「普通话概念」               [⤴]  │
│                                    │
│    铭牌 1   写法/释义    [支持 12]   │ ← 铭牌区（拇指热区）
│    铭牌 2   写法/释义    [支持 8]    │
│    铭牌 3   写法/释义    [支持 3] +N │
│                                    │
│    作者昵称 · 方言点徽章 · 罐头状态   │
├────────────────────────────────────┤
│  首页  图鉴  [＋ 装罐]  集盒  我的   │ ← 自定义 TabBar，中央凸起
└────────────────────────────────────┘
```

## 模块设计

### 1. 顶部栏

- **内容 tab**：今日罐 / 同方言 / 关注 / 推荐，四个 tab 居中排列，当前项加粗下划线高亮；
- **搜索**：tab 行右侧放搜索图标，点击进入独立搜索页（替代目前占一整行的大搜索框）；
- **轻入口**：tab 行左侧放方言圈、发现的小图标入口（次级功能，弱化视觉权重）；
- 「同方言」即本产品语境下的「同城」：按用户主方言及其下级方言点聚合内容。

### 2. 罐头沉浸流（首页主体）

- **一屏一罐**：每屏只完整展示一个罐头，上滑/下滑切换，切换时预取下一罐并停止上一罐音频；
- **核心单元**：一个罐头 = 一段录音 + 若干相关铭牌，这是首页唯一的主角；
- **卡片信息层次**（自上而下）：
  1. 作者头像、昵称、方言点徽章、罐头状态（待校验/社区暂定/正品认证等）；
  2. 播放控件：大号播放按钮 + 播放波形动画 + 时长；
  3. 普通话概念文字；
  4. 铭牌区（见下一节）；
- **沉浸视觉**：深色背景（以品牌深绿为中心的渐变），播放波形动画作为每罐的「视觉画面」，弥补音频无画面的沉浸感缺失；
- **默认内容源**：
  - 已设置主方言的用户默认进入「同方言」；
  - 未设置主方言的用户（含游客）默认进入「推荐」；
- **游客可见性**：游客可浏览、可试听；投票、点赞、评论、装罐需登录，未登录点击时给出登录引导。

### 3. 铭牌区（卡片内，拇指热区）

- 每个罐头卡片内展示**前 3 张活跃铭牌**，每张显示铭文内容与当前支持数；
- 超出部分以「+N 张铭牌」收纳，点击进罐头详情页；
- **卡片上可直接投票**：每张铭牌行内提供「支持」按钮，一键投票/取消投票，即时更新票数（这是产品的「点赞」，是最关键的轻互动）；
- 未登录用户点击支持时引导登录，登录后回到原位置继续。

### 4. 右侧轻互动栏（抖音式）

- 竖排排列：作者头像（带关注态）、赞、评论、分享；
- 与铭牌区分工明确：**右侧是轻互动，铭牌是核心互动**；
- 数字实时反馈（点赞数、评论数）。

### 5. 今日罐（每日回访钩子）

- 顶部独立 tab，每天更新一个精选罐头，制造每日回访理由；
- v1 可采用轻量策略（如按日期轮换的公开罐头），不依赖运营后台。

### 6. 底部导航栏（自定义 TabBar）

- 五个位置：**首页 / 图鉴 / ＋装罐（中央凸起）/ 集盒 / 我的**；
- 「装罐」作为中央凸起的主发布键，是全站最强的行为号召；
- 图鉴、集盒、我的由普通页面升级为 tab 页；
- 发现、方言圈不占 tab 位，收纳到首页顶部轻入口。

### 7. 容错与加载体验

- 加载中显示骨架屏，不出现整页空白；
- 加载失败提供明确的局部重试入口与降级内容（如静态精选罐头），错误提示使用语义色、弱化视觉权重；
- 空状态给出可执行的下一步引导（如「装一罐」「先去选主方言」）。

## 功能验收标准（排版与功能层面）

- [ ] 打开首页首屏即罐头内容，无品牌横幅与功能宫格占据首屏；
- [ ] 一屏一罐，上下滑动切换流畅，切换自动停止上一罐音频；
- [ ] 卡片展示录音播放、普通话概念、前 3 张铭牌及支持数；
- [ ] 铭牌可在卡片上一键投票，票数即时更新；未登录有登录引导；
- [ ] 右侧栏赞/评论/分享可用，数字实时反馈；
- [ ] 今日罐 tab 每日内容不同；
- [ ] 底部 TabBar 五位置可用，中央装罐键凸起且直达装罐流程；
- [ ] 顶部四 tab 切换正确，默认 tab 按主方言状态选择；
- [ ] 游客可浏览试听；搜索图标可达搜索页；方言圈/发现入口可达；
- [ ] 加载失败与空状态均有兜底展示，无整页空白或裸错误横幅；
- [ ] H5 与微信小程序双端布局一致。
